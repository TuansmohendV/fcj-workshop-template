### Week 1 Objectives:

- Get familiar with the working environment and operational regulations at AWS.
- Learn about the AWS cloud computing platform overview and its core services.
- Create a personal AWS account for learning and hands-on practice.

### Tasks to be Executed This Week:

- Study internal onboarding documents, security policies, and standard work processes.
- Read overview documentation on AWS Core Services (Compute, Storage, Database, Networking).
- Register for an AWS Free Tier account and set up basic security measures (such as enabling MFA).
- Explore and get hands-on experience with the AWS Management Console interface.

### Week 1 Achievements:

- **Workplace Adaptation:** Fully understood the workplace culture, information security regulations, and task reporting workflows at AWS.
- **Knowledge Acquisition:** Mastered core concepts of Cloud Computing, the Shared Responsibility Model, and successfully identified foundational AWS services.
- **Practical Environment Readiness:** Successfully created an AWS Free Tier account, configured Multi-Factor Authentication (MFA) for the Root account, and became fluent in navigating and searching within the AWS Console.
