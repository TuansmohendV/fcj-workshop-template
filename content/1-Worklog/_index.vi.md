**Tuần 1:** [Làm quen với môi trường làm việc, tìm hiểu tổng quan về AWS và khởi tạo tài khoản thực hành ](1.1-week1/)

**Tuần 2:** [Nghiên cứu lý thuyết nền tảng về các dịch vụ hạ tầng, kiến trúc mở rộng và giám sát trên AWS (VPC, EC2, RDS, ELB, Auto Scaling, CloudWatch, Systems Manager)](1.2-week2/)

**Tuần 3:** [Thực hành khởi tạo EC2 Instance, cấu hình hạ tầng mạng cơ sở và thiết lập bảo mật bằng Key Pair và Security Group](1.3-week3/)

**Tuần 4:** [Thực hành quản lý chi phí nâng cao trên AWS, thiết lập ngân sách tùy chỉnh và cấu hình hệ thống cảnh báo tự động qua email](1.4-week4/)

**Tuần 5:** [Triển khai hạ tầng mạng VPC, cơ sở dữ liệu RDS MySQL và máy chủ EC2 Windows chạy script tự động cấu hình môi trường ứng dụng TravelBuddy](1.5-week5/)

**Tuần 6:** [Khởi tạo không gian lưu trữ Amazon S3, tổ chức cấu trúc thư mục, nạp dữ liệu mẫu và cấu hình phân quyền bảo mật Bucket Policy](1.6-week6/)

**Tuần 7:** [Triển khai giải pháp quản lý danh tính, phân quyền nâng cao (IAM) và khởi tạo khóa mã hóa đối xứng AWS KMS bảo mật cho dữ liệu lưu trữ](1.7-week7/)

**Tuần 8:** [Khởi tạo khóa mã hóa đối xứng AWS KMS (bật tự động xoay vòng khóa), xử lý lỗi trùng tên hệ thống để tạo S3 Bucket và thực hành tải tệp mã hóa phía máy chủ (SSE-KMS)](1.8-week8/)

**Tuần 9:** [Cấu hình hệ thống giám sát tự động AWS CloudTrail (Multi-region), liên kết lưu trữ tập trung và thiết lập mã hóa bảo mật dữ liệu log trên Amazon S3](1.9-week9/)

**Tuần 10:** [Cấu hình hệ thống phân quyền nâng cao trên AWS IAM cho dịch vụ AWS Glue, thiết lập Custom Policy cấp quyền iam:PassRole theo nguyên tắc đặc quyền tối thiểu](1.10-week10/)

**Tuần 11:** [Khởi tạo hạ tầng lưu trữ Data Lake trên Amazon S3, xây dựng cấu trúc thư mục phân tách dữ liệu và nạp tệp dữ liệu cấu hình/metadata ban đầu](1.11-week11/)

**Tuần 12:** [Phát triển hàm Serverless AWS Lambda trên Cloud9, cấu hình S3 Event Notifications hướng sự kiện và xử lý lỗi tương thích ES Module cho Node.js](1.12-week12/)
